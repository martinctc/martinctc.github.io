A collection of things that I’ve built and shipped - packages, small web apps, and the odd game. Most of them started as tools for my own use, and all of them are open source.

My packages

I’ve authored several R packages, which are all available on GitHub:

Rsurveytoolbox
Tidy support functions for survey analysis.
R📈tstoolbox
Useful tools for time series analysis in R.
Rrwa
Perform a Relative Weights Analysis in R.
R📝textworks
Save time working with survey and text data!
R🗺zipcodes
US zip codes database for R.
R⚙modeltoolbox
Convenience functions for building models in R.
Rgpxtoolbox
Tools for analysing and visualising GPX files.
Rparallaxr
Generate a parallax scroll document in R with YAML and Markdown.
Rdevtoolbox
Tools for the R developer.
Rmschart2
Experimental add-on to {mschart} with native Office chart features.
Rhkdatasets
An R data package containing datasets related to Hong Kong.

Most of these packages were to some extent “by-products” of the analysis that I’ve been doing for the last couple of years, which I decided would have greater value developed into packages.

In addition, I maintain the following packages as part of my work with Microsoft Viva Insights:

Rvivainsights
Analyze and visualize Viva Insights data in R.
Pythonvivainsights-py
Analyze and visualize Viva Insights data in Python.
Rwpa
Analyze and visualize Microsoft Workplace Analytics data in R.
If you have any comments or questions about these packages, please get in touch - any feedback would be valuable!

Vibe-coded projects

Alongside R packages, I’ve recently been building small web apps and tools through “vibe coding” — quick, exploratory builds where I use AI-assisted development to turn an idea into a working tool as directly as possible. These are typically self-contained, browser-based, and built for a specific real-world need of mine.

PythonTrack Tag Manager
A local Python app for tagging and organising tracks, designed for DJ workflows.
TypeScriptTri Harder
An AI-powered triathlon coaching app.
TypeScriptWrava
A local-first writing app that tracks and analyses your writing activity.
TypeScriptDominium
A turn-based strategy game for 2 to 4 players, playable in the browser.
PythonOpenCode Dashboard
A local, read-only dashboard for exploring your OpenCode token usage.
TypeScriptHouse of Cats
An experimental isometric 2.5D browser scene with pixel-art cats.
JS🚲Bike Routes
A curated collection of cycling routes, with maps, elevation profiles and GPX downloads.
JSInterval Tracks
Generated workout audio entirely from code.
JS📝ds-quiz
A single-page assessment tool for data science knowledge.

For a closer look at each of these projects, I’ve written up the ideas and thinking behind them on the vibe-coded projects page.
